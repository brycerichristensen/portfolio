HLS Mission Analysis & Visualization

During my engineering internship at NASA Marshall Space Flight Center (MSFC) in Huntsville, AL, I supported the Human Landing System (HLS) program across two primary initiatives: advancing Terrain-Relative Navigation (TRN) in-the-loop co-simulation capabilities and building automated telemetry analysis pipelines for SpaceX Orbital Flight Tests (OFT). Additionally, I supported the propulsion division with methalox Reaction Control System (RCS) thruster sizing evaluations.

Terrain-Relative Navigation (TRN) In-The-Loop Co-Simulation

Precision lunar landing requires dynamic optical feature matching between onboard cameras and digital elevation models. Previously, TRN visualization operated in an offline "Playback Mode," passing static pre-set .csv telemetry through Python scripts into Unreal Engine to export individual frame files.

I helped transition this architecture into a closed-loop Co-Simulation (In-The-Loop) framework. By linking the GNC simulation directly to an Unreal Engine executable via a custom Simulink-to-UE interface block, the system passes dynamic state vectors in real time, receives rendered optical camera frames and metrics back, and continuously adjusts landing trajectories during flight validation testing.

Optical Descent & Landing Site Validation

The co-simulation pipeline renders realistic lunar surface conditions—including extreme low-angle solar shadowing and crater topography—to test TRN camera tracking robustness during powered descent.

This real-time optical loop allows GNC engineers to evaluate optical feature-tracking algorithms, quantify camera alignment tolerances, and analyze Monte Carlo dispersion patterns across targeted lunar landing sites.

Starship Orbital Flight Test (OFT) Telemetry Automation

Evaluating flight data from SpaceX Starship test launches historically required a manual 2 to 4 day post-flight process involving separate MATLAB plot generation, video splicing in DaVinci Resolve, and manual state inspection.

To streamline this workflow, I engineered an automated processing suite using two core tools:

  • SPAR (State Parser with Anomaly Recognition): Automatically parses .mat telemetry files in 1–2 seconds to detect state changes and trajectory anomalies.
  • VISOR (Video Integration, Splicing, and Overlay Renderer): Slices Unreal Engine renders, overlays telemetry telemetry graphs, and exports completed analysis videos in under an hour.

This automated pipeline slashed total analysis turn-around time from days down to a single day, establishing a pathway toward 2–4 hour turnaround via standalone Unreal Engine executables.

Auxiliary Propulsion: Methalox RCS Thruster Sizing

In addition to GNC visualization projects, I completed propulsive sizing trade studies for a liquid methane and liquid oxygen (methalox) Reaction Control System (RCS) thruster block tailored for deep-space lander attitude control.

The evaluation covered injector orifice geometry trades, spark torch igniter integration options, feed system line pressure drops, and film cooling thermal management calculations to maintain stable impulse bit performance during vacuum operations.
